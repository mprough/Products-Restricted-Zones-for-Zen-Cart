# Security policy

Please do not publish exploitable security details in a public issue. Report security concerns through the [PRO-Webs support desk](https://prowebsinc.zohodesk.com/portal/en/newticket) with the affected version, Zen Cart version, PHP version, and steps needed to reproduce the issue.

Only the current release is maintained. General installation, configuration, and customization assistance is outside the security-reporting process.
