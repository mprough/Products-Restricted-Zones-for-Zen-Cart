Products Restricted Zones v1.1.1 legacy notes

The original loose-file release allowed Product:Zone and CCategory:Zone entries under Admin > Configuration > Products Restricted Zone. It self-installed when an admin page loaded and used uninstall.sql for removal.

Legacy installation required renaming YOUR_ADMIN to the store's admin directory and copying files directly over the admin and catalog directory structure. Those instructions are obsolete for v2.0.0 and later. Install the current package through Zen Cart Plugin Manager.
